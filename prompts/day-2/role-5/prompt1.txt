==================================================
PROJECT CONTEXT
==================================================

ThermalX is a JavaScript-first MVP that detects thermal hotspots using NASA FIRMS data, processes the hotspot data, analyzes persistence and industrial proximity, and eventually classifies hotspots into:

1. Industrial
2. Wildfire
3. Agricultural
4. Other
5. Unknown

The project must remain simple and beginner-friendly during the 10-day MVP development.

DO NOT introduce unnecessary technologies such as:

- React
- Node.js
- Python
- FastAPI
- PostgreSQL
- PostGIS
- TensorFlow
- PyTorch
- Kubernetes
- Docker

The current architecture is:

NASA FIRMS
    ↓
Role 3 — Data Fetching
    ↓
Raw Hotspot Data
    ↓
Role 4 — Data Processing
    ↓
Persistence Detection / Industrial Proximity
    ↓
Role 5 — Classification
    ↓
Role 2 — Leaflet Map
    ↓
Role 1 — Dashboard UI
    ↓
Role 6 — Integration

The project structure should follow:
