# 12. AVERAGE FRP

FRP means Fire Radiative Power.

Use the FRP values associated with the event's valid detections.

Calculate the average only if the processing layer does not already provide it.

Conceptually:

```text
averageFRP =
sum(valid FRP values) /
number of valid FRP values
```

Ignore invalid/non-numeric FRP values.

Do not treat missing FRP as zero.

Example:

Valid values:

20
40
60

Average:

40

If no valid FRP values exist:

```javascript
averageFRP: null
```

Do not return `0` unless the source data actually says the FRP is zero.

# 16. DO NOT SILENTLY CONVERT BAD DATA

Bad:

```javascript
Number(undefined) || 0
```

This can incorrectly turn missing data into a real zero.

Prefer explicit handling.

Example:

```javascript
const averageFRP =
    validFrpValues.length > 0
        ? calculateAverage(validFrpValues)
        : null;
```

This preserves the difference between:

**actual zero**

and:

**missing data**.
