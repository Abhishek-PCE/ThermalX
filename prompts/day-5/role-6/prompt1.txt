# 1. PROJECT CONTEXT

ThermalX is a JavaScript-first web application that:

1. Fetches thermal hotspot data from NASA FIRMS.
2. Displays hotspots on a Leaflet map.
3. Retrieves historical detections.
4. Groups detections into thermal events.
5. Calculates persistence and recurrence.
6. Finds nearby industrial facilities using OSM.
7. Classifies thermal events later using explainable rule-based logic.
8. Displays evidence, confidence and priority in the dashboard.

The overall MVP flow is:

NASA FIRMS
→ Data Fetching
→ Raw Hotspot Data
→ Data Processing
→ Persistence Detection
→ Industrial Proximity
→ Classification
→ Leaflet Map
→ Dashboard UI
→ Integration

Do NOT change this architecture unnecessarily.

# 10. TEST PERSISTENCE CALCULATION

The roadmap defines the prototype persistence calculation as:

Persistence =
days detected / days analysed
