# DAY 4 ROLE 4 OBJECTIVE

Implement the **data-processing layer required for industrial proximity analysis**.

The system should be able to:

1. Receive a hotspot.
2. Receive nearby industrial facilities from OSM/Overpass.
3. Validate their coordinates.
4. Calculate the geographic distance between the hotspot and each facility.
5. Sort facilities by distance.
6. Identify the nearest facility.
7. Store the calculated distance in a clean data structure.
8. Return the processed information so Role 1 can display it and Role 5 can later use it for classification.

# STEP 3 — USE TURF.JS FOR DISTANCE CALCULATION

Use **Turf.js** for geographic distance calculations.

Do NOT calculate geographic distance using a simple difference such as:

```javascript
Math.sqrt(
    Math.pow(lat1 - lat2, 2) +
    Math.pow(lon1 - lon2, 2)
)
```

That is not an appropriate geographic distance calculation.

Use Turf.js point features and Turf's distance functionality.

The distance should preferably be represented in **kilometers** because ThermalX will display distances such as:

```text
1.2 km
3.8 km
12.4 km
```

Keep the raw numerical distance available for calculations.

---

# STEP 4 — CREATE A REUSABLE DISTANCE FUNCTION

Create a reusable function similar in purpose to:

```javascript
calculateDistanceBetweenHotspotAndFacility()
```

The exact function name can follow the existing coding style.

The function should:

* accept hotspot coordinates
* accept facility coordinates
* create Turf points
* calculate distance
* return distance in kilometers

Example conceptual result:

```javascript

```

Every distance must be calculated from the actual coordinates.
