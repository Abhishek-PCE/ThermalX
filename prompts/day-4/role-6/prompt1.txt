# 6. SELECTED HOTSPOT FLOW

When the user selects a hotspot:

1. Get the hotspot latitude.
2. Get the hotspot longitude.
3. Validate both values.
4. Send the coordinates to the OSM/Overpass functionality.
5. Request nearby relevant industrial facilities.
6. Handle the response.
7. Normalize the facility data.
8. Calculate distance between:

   * selected hotspot
   * each nearby industrial facility
9. Sort facilities by distance if appropriate.
10. Display the results.

Example:

Selected hotspot:

Latitude: 25.5941
Longitude: 85.1376

Nearby facilities:

Factory A
Distance: 1.2 km
Type: Industrial Facility

Power Plant B
Distance: 3.8 km
Type: Power Plant

---

# 7. DATA VALIDATION

Before using OSM data, validate it.

Handle:

* missing latitude
* missing longitude
* invalid latitude
* invalid longitude
* missing facility name
* missing facility type
* incomplete OSM objects
* duplicate facilities
* unexpected response structure
* empty response
* malformed response

Never allow invalid data to crash the application.

Use safe fallback values where appropriate.

For example:

Unknown Facility

Unknown Type

Distance unavailable

But do not invent actual facility information.

---

# 8. DISTANCE CALCULATION

The system must calculate the distance between:

HOTSPOT → INDUSTRIAL FACILITY

Use Turf.js if Turf.js is already part of the project.

Otherwise, implement a simple reliable geographic-distance calculation without introducing unnecessary dependencies.

Prefer returning distance in kilometers.

Example:

Distance = 1.2 km

For very small distances, use an appropriate readable unit if useful.

The distance calculation must:

* use valid coordinates
* return a numeric value
* avoid NaN
* avoid negative values
* handle missing coordinates safely

---

# 9. INDUSTRIAL RELEVANCE

The distance should be available to the classification system later.

For now, do NOT claim:

"this hotspot was caused by the factory."

Instead use responsible wording such as:

"Nearby industrial facility detected."

or:

"Industrial context detected at 1.2 km."

Remember:

DISTANCE IS CONTEXT, NOT PROOF OF CAUSE.

The roadmap describes industrial proximity as a decision-support heuristic, not proof of attribution.
